# 노션 → PROJECT.md 동기화

PROJECT.md는 노션 기획 문서의 사본입니다. 이 스킬은 노션이 연결된 담당자만 실행합니다.

## 절차

1. **원본 찾기**: PROJECT.md 머리말의 `노션 원본:` 줄에서 URL을 읽습니다.
   - "(아직 연결 안 됨)"이면 사용자에게 노션 페이지 URL을 묻습니다. 받은 URL은 4단계에서 머리말에 적습니다.
2. **노션 읽기**: Notion MCP로 그 페이지와 하위 페이지·데이터베이스를 읽습니다.
   - 노션 도구가 없거나 권한 오류가 나면 멈추고 사용자에게 알립니다. 기억이나 추측으로 채우지 않습니다.
3. **차이 정리**: 지금 PROJECT.md와 노션 내용을 비교해 "추가 / 변경 / 삭제" 목록을 만듭니다.
   - 특히 **알파 범위**(꼭 해야 / 하면 좋은 / 나중)와 **성공 기준**이 바뀌었는지 먼저 봅니다. 에이전트가 무엇을 먼저 만들지가 여기서 정해집니다.
4. **다시 쓰기**: PROJECT.md를 노션 기준으로 다시 씁니다.
   - 섹션 순서는 지금 문서를 유지합니다. 노션에 새 주제가 생겼으면 알맞은 위치에 섹션을 추가합니다.
   - 노션에 없는 내용을 지어내지 않습니다. 노션에서 사라진 항목은 지웁니다.
   - 머리말의 `노션 원본`과 `마지막 동기화`(오늘 날짜)를 갱신합니다.
5. **영향 확인**: 바뀐 기획 때문에 AGENTS.md나 ARCHITECTURE.md와 어긋나는 곳이 있으면 목록으로만 보고합니다. 그 문서들은 고치지 않습니다.
6. **보고**: 3단계의 차이 목록을 보여줍니다. 커밋은 사용자가 요청할 때만 AGENTS.md 커밋 체크리스트대로 합니다(브랜치 예: `docs/sync-project`, 메시지 예: `docs: 노션 기획 동기화`).
