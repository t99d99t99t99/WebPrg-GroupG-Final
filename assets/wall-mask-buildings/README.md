# 벽면 마스크

각 PNG는 이름에 대응하는 건물 스프라이트와 같은 크기이며, 흰색 불투명 픽셀이 착색할 외부 벽면입니다. 홈페이지와 디버그 페이지는 이 파일을 그대로 읽습니다.

모든 건물 마스크는 이 폴더의 `wall-mask-<건물 원본 파일명>` 규칙을 따릅니다. 예를 들어 `bld_house_small_blue_a.png`의 마스크는 `wall-mask-bld_house_small_blue_a.png`입니다. 사용 중인 계열과 단계별 건물은 [건물 계열 목록](../../BUILDING_FAMILIES.md)을 참고합니다.

통합된 중복 주택과 폐지된 갈색 벽돌 주택 계열의 마스크 32개는 파일만 보존하며 홈페이지와 디버그 페이지에서는 사용하지 않습니다. 구체적인 목록은 위 문서의 **통합·미사용 건물**에 명시합니다.

- 상점 지붕에서 벽과 같은 재질인 테두리·난간은 포함합니다. 지붕 중앙 바닥·차양·간판·그림자·지면은 제외합니다.
- 벽돌 건물은 벽돌만 포함하고, 벽돌 사이의 줄눈은 제외합니다.
- 상점의 문틀·창틀, 벽 모서리, 벽과 지붕 테두리의 접합부는 벽면에 포함합니다. 유리·문짝·차고 내부·파손 부위의 판자는 제외합니다.
- 파손 얼룩은 벽면에 포함합니다. 정상·파손 이미지의 벽 모서리와 테두리는 같은 면 경계를 사용합니다.
- `fruitstand`는 외부 측면 패널만 포함합니다. 진열 공간·상품·상자·기둥·바닥은 제외합니다.
- 공사 에셋 두 개는 벽면이 없으므로 마스크 전체가 투명합니다.

`debug/building-color-test/building-color-test.html`의 **마스크 강조**에서 실제 선택 영역을 원본 위에 표시해 확인할 수 있습니다.
각 카드의 **마스크 편집**에서 픽셀 단위로 수정하고 PNG를 저장할 수 있습니다. 완료한 변경 내용은 현재 탭 세션에 유지되며, 목록에서 변경된 마스크 또는 전체 마스크를 ZIP으로 받을 수도 있습니다. 저장한 파일을 이 폴더의 같은 이름으로 교체해야 실제 건물에 적용됩니다.
